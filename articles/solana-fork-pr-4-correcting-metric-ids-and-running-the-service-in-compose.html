Carries the parts of #1 that are still worth having, and leaves behind the parts main has since moved past. Opened instead of merging #1 directly, because merging #1 wholesale would revert four files to their 7 August state.

The bug

The metric id to name map on main disagrees with the data. Checked against apps/sdp-metrics-api/insert-values.csv, which mirrors dev.mlh.metrics and is byte-identical on main and on ari-branch:

idtruthmain said
14SlotsDEX Transactions
24DEX Tradersmissing entirely
25DEX TransactionsValidator Count
28SOL Price (Network)Slots
29Validator CountSOL Price (Network)

/metrics has been serving real numbers under the wrong headings. Worse than serving none, because a caller cannot tell it is wrong.

Also fixes the grouping loop. partition_by(&quot;date&quot;, as_dict=True) returns a dict keyed by the partition tuple, so iterating it directly walks the keys and never the frames.

Compose

sdp-polars-api was the one service in the stack with no compose entry, so a local run could not exercise the routes this PR fixes. Added alongside sdp-metrics-api, not replacing it - the two expose different route sets. The health check is defined here because the image declares none, and it probes /health, which does not touch S3 and so cannot flap on Delta table availability.

Validated with docker compose config (exit 0).

One of three PRs. Review all three; merge in this order:

  1. #2670: repo chore, independent
  2. #2669: the service (this PR)
  3. #2671: builds on #2669; sync after it merges

Adds apps/sdp-metrics-api, a standalone Python service from the MLH Fellowship for Solana. It reports how active an SPL mint is, using Delta tables on S3 with a Solana RPC fallback. Background, AWS and open questions.

  • Routes: GET /rpc (count, cache state in X-Cache), GET /rpc/series, POST /insert, GET /healthz.
  • Writes and overrides are gated: /insert needs X-API-Token and answers 503 without a token or bucket. ?rpc= is off by default.
  • No default bucket, so no tie to any AWS account: set S3_INSERT_BUCKET and your own credentials.
  • Only adds files. Nothing calls it, and it isn't in docker-compose.yml, OpenAPI or the docs.
  • First Python in this repo: CI won't run its tests.

Co-authored with Arianna (@starry-ari). Waddah (@waldruupi) guided the data work.

Verification: pytest 75 passed with a fake RPC and real local Delta tables; rebuilt the image and checked its routes on live devnet. Not run: real S3, pnpm test:integration. pnpm: no test failed on both this and main; failures were local timeouts (details).
