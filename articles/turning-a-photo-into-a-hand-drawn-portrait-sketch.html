Portrait Gallery

A professional-grade web application designed for generating high-quality hand-drawn portrait sketches from digital photographs. The system follows a decoupled architecture using a modern Next.js frontend and a high-performance PyTorch/OpenCV backend.

Architecture Overview

The application is split into two primary components:

1. Backend (Python / Flask)

The backend manages image processing using a dual-stage pipeline:

  • Salient Object Detection: Utilizes the U2-Net (Universal U-Square Net) architecture to accurately isolate human subjects from backgrounds.
  • Synthetic Sketch Engine: An OpenCV-based post-processing system that applies morphological operations, Gaussian blurring, and dodge-blending to create organic pencil-style portraits.

2. Frontend (Next.js / React)

The frontend provides a premium gallery experience:

  • Modern UI/UX: Features glassmorphism, fluid animations, and a responsive grid layout.
  • Interactive Capture: Support for both direct image uploads and live camera streams.
  • Aesthetic Design: Minimalist dark-mode aesthetic optimized for visual clarity.

Installation and Setup

Prerequisites

  • Python 3.9+
  • Node.js 18+
  • PyTorch (CPU or CUDA enabled)

Backend Configuration

  1. Navigate to the project root.
  2. Create a virtual environment: python -m venv venv.
  3. Activate the environment and install dependencies: pip install -r requirements.txt.
  4. Ensure the u2net.pth model file is present in the root directory.
  5. Launch the server: python app.py.

Frontend Configuration

  1. Navigate to the next-client-new directory.
  2. Install dependencies: npm install.
  3. Launch the development server: npm run dev -- -p 3005.

Usage

Once both servers are operational, navigate to localhost:3005. Use the studio interface to upload an image. The system will automatically process the portrait and add it to your persistent gallery.

# -------------------- U2-Net Model Definition --------------------
class REBNCONV(nn.Module):
    def __init__(self, in_ch=3, out_ch=3, dirate=1):
        super(REBNCONV, self).__init__()
        self.conv = nn.Conv2d(in_ch, out_ch, 3, padding=1*dirate, dilation=1*dirate)
        self.bn = nn.BatchNorm2d(out_ch)
        self.relu = nn.ReLU(inplace=True)
        
    def forward(self, x):
        return self.relu(self.bn(self.conv(x)))
